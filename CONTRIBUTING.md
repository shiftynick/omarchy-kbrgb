# Repository maintenance

This is the source repository for the `shifty.kbrgb` Omarchy shell plugin.
The active local installation may be a separate copy under:

```text
~/.config/omarchy/plugins/shifty.kbrgb/
```

Keep the repository copy authoritative for public changes. Before publishing
an update, copy or link the repository contents into the installed plugin
folder, run the tests, validate the manifest, and rescan the shell.
